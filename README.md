# Expense Tracker

Gestor de gastos personales en Python con persistencia en JSON.

## Instalación

pip install -r requirements.txt

## Uso

python main.py

## Estructura del proyecto

- `models.py` — validación de transacciones y cálculo de totales
- `storage.py` — carga y guardado de datos en JSON
- `main.py` — punto de entrada del programa
